# Executive Summary

VTK (see [repository](https://gitlab.kitware.com/vtk/vtk) and [website](https://vtk.org/)) is developing a WebGPU rendering backend to create one modern graphics path that can operate across native desktop systems and WebAssembly applications. The effort addresses an escalating maintenance problem: supporting medical and scientific rendering separately through OpenGL, browser APIs, Vulkan, Metal, and Direct3D multiplies window-system integration, shaders, resource management, testing, and defect correction. WebGPU exposes a portable modern API, while Dawn maps that API to native graphics implementations.

The central architectural change separates operating-system window ownership from graphics rendering. `vtkHardwareWindow` and its platform subclasses manage Win32, Cocoa, X11, Wayland, and WebAssembly surfaces. `vtkWebGPURenderWindow` consumes those surfaces and owns WebGPU adapters, devices, textures, buffers, pipelines, and presentation. This decoupling removes the need to build an entire WebGPU render-window stack for each platform and better supports Qt embedding, compositor-managed Wayland windows, headless rendering, and browser canvases.

The backend has progressed from foundational polygonal rendering toward practical feature coverage. 2026 work added or strengthened 2D image rendering, all VTK light types, skyboxes, batched polydata, 16-bit texture support relevant to medical images in WASM, resizing and finalization, physically based rendering, and render-pass infrastructure. Volume rendering remained an active development area at the August 3, 2026 reporting point. The team is also working toward the standardized WebGPU C API to reduce coupling to a specific Dawn C++ version.

WebGPU's primary value to VTK is sustainability and continuity, not a claim that a portable layer will always outperform hand-tuned native APIs. The backend needs ongoing image-regression tests, cross-platform GPU CI, feature-parity tracking, and representative benchmarks. When complete, it can support the same VTK scene architecture on workstations and in browsers, reducing duplicated code while making modern GPU rendering available to a broader community.
