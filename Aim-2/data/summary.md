# Executive Summary

The AI-Data thrust in Aim 2 uses visualization to expose how an AI model behaves. It complements the AI transfer-function thrust, which uses AI to create a visualization. During the prior reporting period, the project built a foundation of model-derived medical-imaging data and a trame/VTK prototype. Major new AI-Data implementation is not active in 2026 and is planned to resume later in 2027.

The work addresses three complementary questions. **Explainability** asks where a model focused when making a decision. A DenseNet-121 lung-lesion classifier produced LayerCAM maps from multiple layers, allowing early local responses and deeper semantic responses to be inspected separately or combined. An XAITK-based prototype also reconstructed slice-level saliency results into a 3D CT-aligned volume. **Sensitivity** asks how predictions change when input regions are perturbed. Occlusion experiments demonstrated the tradeoff between smaller, more detailed masks and larger, less expensive masks. **Uncertainty** asks how stable predictions are. A 3D UNet brain-tumor segmentation workflow used test-time augmentation for data-related uncertainty and Monte Carlo dropout for model-related uncertainty, producing mean, mode, standard deviation, volume-variation measures, and voxel-wise uncertainty volumes.

These outputs were designed as spatially aligned data products rather than static illustrations. A trame prototype combined 2D slice views and 3D volume rendering so users could inspect medical images together with saliency or uncertainty. This establishes a path for VTK to treat model focus, sensitivity, and confidence as first-class arrays that can be registered, filtered, rendered, compared, and explored interactively.

The current foundation has important limitations. The available sensitivity output is still closer to a summarized saliency volume than a complete perturbation dataset. A full implementation would preserve one 3D result per localized perturbation, along with model, parameter, and spatial provenance. The visual interface also needs linked multi-view layouts, hierarchical inspection, careful color and opacity design, and domain-expert evaluation. Interpretability visualizations can reveal suspicious behavior, but they do not themselves establish model correctness or clinical validity.

When work resumes later in 2027, the recommended focus is to standardize the data model, complete the sensitivity stack, integrate reproducible computation with the viewer, and evaluate how users reason across anatomy, saliency, perturbation response, and uncertainty. Until then, the 2025 datasets and prototype should be reported as the completed foundation, while the richer VTK integration remains planned work.
